# Licenciamento

A licença pública ainda deve ser escolhida pelo autor antes da publicação.

O projeto possui dois tipos de conteúdo:

1. **Código-fonte e exemplos**.
2. **Texto autoral do livro**.

É possível usar licenças diferentes para código e texto. Não publique um arquivo `LICENSE` definitivo até decidir quais permissões deseja conceder para cópia, modificação, redistribuição e uso comercial.
