# Contribuindo

1. Abra uma issue descrevendo a correção ou melhoria.
2. Crie uma branch.
3. Faça alterações pequenas e focadas.
4. Execute `ruff check src tests`.
5. Execute `pytest -q`.
6. Abra um pull request explicando o impacto no livro e/ou código.

Correções de conteúdo devem informar o capítulo afetado.
